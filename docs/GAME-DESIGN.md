# 게임 기획 / 구현 기준

## 현재 게임
- 이름: **어쩌구 키우기**
- 형태: 웹 기반 일러스트레이터 작업실 운영·성장 방치형 게임
- 핵심 진행: 의뢰 수락 → 시간 경과에 따른 작업 진행 → 납품 → 게임 재화·EXP 획득 → 성장
- 현재 주요 기능: 일반 의뢰, 작업 대기·예약·도착함, 타입별 접수 설정, 자동 작업/수락/연습, 피로와 수동 수면, 레벨·스탯, 도감(외주 신청자 데이터 제공 시), 게임 기록
- 현재 재화 지출: 주간 식비, 작은 복권, 상점 상품·오프라인 업그레이드. 이벤트·장비 점검·작업실 홍보·전시 참가 지출은 제거됨.
- 저장: localStorage (`studio.workbench.v2`)와 저장 JSON 내보내기·불러오기. 엔진 포맷 v3.

## 확정된 상위 탭
| 순서 | 메뉴 | 이번 작업 범위 |
| --- | --- | --- |
| 1 | 작업실 | 기존 홈과 의뢰·성장 기능 접근 유지 |
| 2 | 집 | 임시 탭 / 준비 중 화면 |
| 3 | 상점 | 탄산음료 구매·사용, 오프라인 타블렛/의자 업그레이드, 기타 소비처 미구현 |
| 4 | 가챠 | 임시 탭 / 준비 중 화면 |
| 5 | 기록 | 수입·지출·사건 하위 탭과 각 18개씩 페이지 표시 |

이전 좌측 메뉴의 작업대는 작업실 메인 화면에 이미 포함된 기능이다. 성장·운영은 PC에서 오른쪽 패널, 모바일에서 작업실 하단 인라인 영역으로 접근한다. 작업실 상단에 별도 이동 버튼은 두지 않는다.

## 게임 재화 소비처 — 미확정 후보
다음은 논의를 위한 **아이디어**이며 확정된 기능·경제 밸런스가 아니다.

| 화면 | 가능한 사용처 | 결정해야 할 것 |
| --- | --- | --- |
| 집 | 가구 구입, 인테리어 꾸미기, 생활 공간 확장 | 외형 꾸미기 전용인지, 피로 회복이나 보너스를 제공할지 |
| 상점 | 작업 도구, 소모품, 꾸미기 아이템 | 카테고리, 가격, 효율, 중복 구매, 인벤토리 |
| 가챠 | 게임 재화로 획득하는 수집 아이템 | 재화 비용, 뽑기 횟수, 확률, 등급, 중복/보장 정책 |

탄산음료는 구매 시 인벤토리에 보관하고 사용 시 피로도를 회복한다. 다른 품목·가챠의 구매·추첨은 구현되지 않았고, 사용자 승인 전 아이템 가격·뽑기 확률·확률 보장 규칙 등을 임의로 정하지 않는다. 현재는 현실 결제나 현금 전환 없이 **게임 내 재화 사용처**를 구상하고 있다.

## 화면 설계 기준
- 화면은 깔끔하고 기능 중심으로 구성한다.
- 아무 기능이 없는 감성 카피, 설명 박스, 임의 브랜드명은 추가하지 않는다.
- 데스크톱은 좌측 메뉴, 작은 화면은 하단 메뉴의 5개 버튼을 제공한다.
- PC의 게임 프레임 비율과 내부 스크롤을 보존한다. 1,050px 미만에서는 프레임을 화면 높이에 맞추고 하단 메뉴를 고정한다.
- 작업실에서 성장·운영을 읽고 조작할 수 있게 하며, 모바일에서는 의뢰의 대기함·예약함·도착함 중 선택한 목록만 표시한다.

## 상점 아이템 개발 도구 (첫 번째 확정 아이템)

- 가격: **2,200원**
- 사용 효과: **피로도 10 감소(즉시 적용을 위한 데이터 정의)**

아이템 제작 도구는 아이템 목록·가격·이미지 경로·효과를 편집하고 JSON 파일을 가져오거나 내보내는 별도의 개발 페이지다. 이후를 위한 효과 유형 필드(피로도 변화, 시간제 버프, 디버프 해제)를 제공한다. 시간제 버프와 디버프 해제는 데이터 편집을 위한 템플릿일 뿐 **효과·지속시간이 게임 엔진에 구현된 것은 아니다**.

**구현 완료(탄산음료만)**: 상점 탭 상품 표시, 잔액 확인, 2,200원 결제와 인벤토리 보관, 사용 시 피로도 최대 10 감소, 지출·기록·저장 반영. 피로도가 10보다 낮으면 0에서 멈추며 가격은 동일하다. 피로도 0에서도 구매할 수 있으나 사용할 수는 없다.
**미확정**: 기타 아이템의 구매/사용 UI, 버프·디버프 해제 엔진 효과.

### 장비 시스템 관련 원칙
기존의 **작업 속도용 장비 업그레이드**는 사용자 결정으로 폐기되었다. 오프라인 보상 전용 타블렛/의자 업그레이드와 구별한다. 예전 장비 아이콘(`assets/03-equipment.webp`) 및 장비 업그레이드 UI/CSS를 다시 추가하지 않는다. 엔진의 구버전 저장 마이그레이션 및 강화비 환급 코드는 기존 사용자 호환을 위해 보존한다. 별도 장비 점검 이벤트와 설정은 2026-10-11 제거했다.

## 의뢰·식비 밸런스 (2026-10-10 확정)

**기준**: 아래 작업 시간은 버프·성장 보정이 적용되기 전 **게임 시간**이며, 게임 1분 = 실제 1초다. 일반 의뢰가 새로 생성될 때 작업량(게임분)과 기본 보상금(원)을 각 구간의 양 끝을 포함하여 **각각 정수 균등 추첨**한다. 현재 저장된 의뢰는 기존 작업량·보상금을 그대로 유지한다.

| 종류 | 작업 시간 (게임 기준) | 기본 보상금 |
| --- | --- | --- |
| 낙서 두상 | 20~25분 | 5,000~10,000원 |
| 낙서 흉상 | 35~40분 | 12,500~18,000원 |
| 낙서 반신 | 45~55분 | 23,000~28,500원 |
| 낙서 전신 | 60~70분 | 35,000~42,000원 |
| 단색 두상 | 35~45분 | 20,000~25,000원 |
| 단색 흉상 | 47~55분 | 27,000~30,000원 |
| 단색 반신 | 60~70분 | 38,000~45,000원 |
| 단색 전신 | 90~110분 | 50,000~60,000원 |
| 풀채색 두상 | 60~90분 | 50,000~60,000원 |
| 풀채색 흉상 | 80~120분 | 60,000~75,000원 |
| 풀채색 반신 | 150~240분 | 90,000~130,000원 |
| 풀채색 전신 | 210~300분 | 120,000~180,000원 |

- 신규 의뢰는 `engine.js`의 `JOB_BALANCE` 테이블을 사용한다. 아이템·의뢰 내용과 무관한 기존 시스템은 그대로다.
- 기본 보상금에 기존 실력 보정 `(1 + skill × 0.005)`를 적용하고 정수 내림한다. 따라서 성장 후 실제 지급액은 이 표의 상한을 초과할 수 있다.
- 실제 작업 시간은 작업 속도 스탯을 반영한다. 피로도 90 이상이면 해당 속도에 0.5를 곱하며, 기존 임시 버프는 적용하지 않는다.
- 외주에는 기존 보상금 ×1.7(정수 내림), EXP ×1.25(정수 내림)가 추가된다.
- 이 표의 보상 EXP, 의뢰 해금 레벨, 기본 도착 확률, 마감 기한은 유지한다.
- **식비:** 게임 1일당 25,000원 기준, 매 게임 7일 경과 시 **175,000원**을 한 번에 차감한다. 놓친 주차가 있으면 그 주 수만큼 지출한다. 첫 결제 시점은 기존의 게임 7일 주기 로직을 유지한다.
- 게임 저장 스키마 v3와 키 `studio.workbench.v2`는 유지한다. 기존 저장의 의뢰 `work`, `gold`, `done` 값을 재계산하지 않는다.

## 신규 시작 자금 (2026-10-10 확정, 2026-10-11 홍보 제거)
- 새로운 작업실을 시작하면 초기 자금 **100,000원**을 지급한다. 초기 자금은 누적 수입에 포함하지 않는다.
- 기존 저장 데이터를 불러오거나 이어서 플레이하면 기존 잔액을 유지한다. 기존 플레이어에게 시작 자금 100,000원을 소급 지급하지 않는다.
- 작업실 홍보 기능·비용·일시 효과는 2026-10-11 제거했다. 이전 세이브에 있던 활성 홍보 효과도 더 이상 적용하지 않는다.
- 주간 식비는 게임 7일마다 175,000원. 기존 저장 포맷(v3)·키(`studio.workbench.v2`)와 다른 게임 규칙은 유지한다.

## 오프라인 진행과 전용 업그레이드 (2026-10-10 확정)
- **오프라인 판정**: 웹페이지를 완전히 닫았다 다시 열 때의 경과 시간과 브라우저 탭이 백그라운드인 시간 모두 적용. 게임 1분은 실제 1초. 새 버전에서 저장 시 `savedAt`을 함께 기록하며, 해당 정보가 없는 기존 저장은 과거 미접속 시간을 추정하지 않는다.
- **오프라인 의뢰 진행**: 작업 진행률 100%, 피로도·수면 및 기타 지출 100%.
- **오프라인 보상**: 의뢰 완료 보상금 기본 10%; 해당 의뢰의 획득 EXP 기본 10%. 오프라인 자동 그림 연습 EXP에도 의자 보정 적용. 보상·EXP는 정수 내림.
- **온라인 상태**: 보상금·EXP 각 100% 지급. 오프라인 업그레이드는 온라인에는 영향을 주지 않는다.
- **타블렛**: 오프라인 의뢰 완료 보상금 비율 증가. **의자**: 오프라인 의뢰 완료 및 그림 연습 EXP 비율 증가.
- 각 아이템은 **Lv.0~5**, 증가분은 단계별로 **+3%p, +5%p, +7%p, +10%p, +15%p**. 최종 비율은 **10% → 13% → 18% → 25% → 35% → 50%**. 두 장비의 업그레이드 수준은 독립적.
- 단계별 업그레이드 비용(타블렛/의자 각각 동일): Lv.1 **250,000원**, Lv.2 **750,000원**, Lv.3 **1,500,000원**, Lv.4 **5,500,000원**, Lv.5 **20,000,000원**. 중복 구매는 단계가 올라가는 방식이며 Lv.5에서 종료.
- 구매 장소는 게임 **상점** 탭, 아이콘은 사용자가 첨부한 32×32 투명 PNG 파일 `assets/shop/pen-tablet.png`, `assets/shop/chair.png` 사용.
- 기존에 폐기한 **작업 속도용 장비 강화 기능**과는 별개의 **오프라인 보상 전용 업그레이드**다. 예전 장비 업그레이드 에셋(`03-equipment.webp`)이나 업그레이드 UI를 복원하지 않는다.
- 저장 버전 v3 유지: `offlineUpgrades:{tablet:0..5,chair:0..5}` 필드를 추가하고, 기존 저장에서 누락된 필드는 0단계로 자동 처리. 잔액·기존 의뢰·이전 게임 기능을 재설정하지 않는다.
- 게임 탭 완전 종료·백그라운드 정산은 `app.js`의 누적 시간 큐를 통해 순서대로 처리한다. 장기간 미접속 정산은 분할 진행되며 진행 중에는 구매·업그레이드 작업을 막는다. 아직 PC/모바일 실브라우저 E2E 검증은 별도 확인 필요.

## 그림 연습 및 상점 오른쪽 패널 (2026-10-11)
- **그림 연습**: 한 번의 연습은 게임 시간 **30분**, 완료 시 **2 EXP**. 기존 자동·수동 연습과 피로 누적은 유지하며, 피로도 90 이상에도 강제 수면하지 않는다.
- 오프라인에서도 연습 진행 시간과 피로도는 그대로 처리하고, 연습 EXP에는 기존 오프라인 EXP 보정(기본 10%, 의자 Lv.5에서 50%)을 적용한 후 정수 내림한다. 현재 수치에서는 **기본 단계 오프라인 연습 보상 0 EXP**, 의자 Lv.5에서는 1 EXP다. 별도의 최소 보상은 추가하지 않는다.
- **식비**: 게임 하루 25,000원 기준으로 계산하지만 실제 지출은 **게임 7일마다 175,000원 일괄 차감**. 부족한 경우 잔액이 음수가 되는 기존 규칙은 유지.

- **상점 화면 구성**: 메인 상점 영역에는 상점 소모품 목록(탄산음료 등)을 표시하고, 오른쪽 기존 노트 패널 공간에 **상단 소형 액정 타블렛·의자 업그레이드, 하단 인벤토리 영역**을 표시한다.
