## 2026-10-11 — 연습 30분·2 EXP, 식비 175,000원 및 상점 오른쪽 패널
- 그림 연습 시간을 240게임분 → **30게임분**, 온라인 완료 EXP를 15 → **2**로 변경. 자동 연습·수동 연습, 피로·수면과 오프라인 EXP 비율은 종전대로 유지.
- 오프라인 그림 연습 EXP는 소수점 이하 버림이 적용되므로 기본 10%일 때 0 EXP, 의자 5단계(50%)일 때 1 EXP.
- 주간 식비를 게임 하루 25,000원 기준 **7일마다 175,000원 지출**로 변경. 7일 주기와 잔액 음수 가능 규칙은 변경하지 않음.
- 기존 v3 세이브의 240게임분 기준 연습 진행도는 새 30게임분 기준으로 비례 환산, `practiceDuration:30` 마커로 중복 환산 방지.
- 상점 화면의 오른쪽 기존 성장 노트 자리에는 **상단 소형 타블렛·의자 업그레이드, 하단 인벤토리 영역**을 배치. 모바일은 상점 상품 아래에 배치.
- 현재 보관 가능 상품이 없어 인벤토리는 '보유 아이템 없음'을 표시. 탄산음료의 기존 구매 즉시 사용 규칙 및 저장 방식은 유지.
- `engine.js`, `app.js`, `reference.css`, 관련 테스트 및 문서 갱신. 게임 내 신규 메뉴나 별도의 소비 규칙 추가 없음.
- 검증: GitHub 최신 JS로 신규·기존 회귀 **609개 단위 검사 통과**. 실제 브라우저 UI 및 종료 후 재진입 테스트 미검증.
