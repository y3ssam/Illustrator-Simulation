## 2026-10-10 — 의뢰 작업 시간·보상금 범위 및 주간 식비 조정
- `engine.js`: 12종 의뢰의 작업량·보상금 구간을 `JOB_BALANCE` 테이블로 분리하고, 새 의뢰 생성 시 각 구간에서 정수 균등 추첨

- 풀채색: 두상 60~90분 / 50,000~60,000원, 흉상 80~120분 / 60,000~75,000원, 반신 150~240분 / 90,000~130,000원, 전신 210~300분 / 120,000~180,000원
- 실력·작업 속도·외주 보정, EXP, 마감, 저장 포맷 v3와 기존 저장 키 변경 없음. 과거 생성된 의뢰의 기존 보상·작업량 보존.
