# 변경 기록

## 2026-10-10 — 게임 상점에 탄산음료 적용
- `app.js`: 상점 탭이 `data/shop-items.json`을 읽고 탄산음료(아이콘·가격·피로도 감소)를 표시하도록 변경
- **구매·사용**: 2,200원을 차감하고 피로도를 즉시 최대 10 감소. 구매 즉시 소비하므로 인벤토리 추가 없음.
- 피로도 0·잔액 부족·미지원 효과 타입은 구매 비활성화/실패, 상태 변화 방지
- `engine.js`: 구매 가능 여부 및 구매 적용 함수 추가, 누적 지출과 운영 로그 갱신
- 기존 게임 저장 키 `studio.workbench.v2`와 v3 저장 포맷 유지, 구버전 데이터 호환 코드는 변경하지 않음
- `reference.css`: 상점 PC·모바일 화면 레이아웃
- `tests/shop-purchase.test.js`: 정상 구매, 잔액 부족, 피로 하한, 피로도 0, 저장 재불러오기 확인용 테스트 추가

### 검증
- JavaScript 구문·파일 경로·상품 데이터 구조 확인
- 첨부된 원본 엔진에 동일한 구매 함수를 적용한 로컬 Node 단위 검사 통과
- GitHub 저장소 전체 클론/테스트 및 실제 브라우저 상호작용 테스트 미실시 (테스트 환경에서 github.com DNS 접근 불가)

## 2026-10-10 — 상점 아이템 제작 도구·장비 업그레이드 잔여 코드 정리
- `tools/shop-editor.html`, `tools/shop-editor.css`, `tools/shop-editor.js`: 독립 아이템 편집 화면 추가
- 아이템 생성·편집·삭제, 아이콘 미리보기, JSON 가져오기·내보내기, 로컬 편집 저장 기능
- 아이템 효과 데이터 유형: 피로도 즉시 변화 / 시간제 버프 / 디버프 해제 (게임 엔진 미연결)
- `data/shop-items.json`: 첫 아이템 **탄산음료 / 2,200원 / 피로도 -10**

- `reference.css`, `style.css`, `cozy.css`에서 제거된 장비 업그레이드 화면·장비 이미지의 잔여 스타일 삭제
