# 어쩌구 키우기

일러스트레이터 작업실 운영 방치형 웹게임입니다. 이 저장소를 게임 소스와 개발 문서의 기준 저장소로 사용합니다.

## 실행
정적 HTML/JavaScript 프로젝트입니다. `index.html`을 로컬 웹서버로 열어 실행합니다. 브라우저 저장은 localStorage 기반이며, 설정에서 JSON 파일로 내보내거나 가져올 수 있습니다.

## 메뉴
작업실 → 집 → 상점 → 가챠 → 기록

현재 집·상점·가챠는 화면 진입만 가능한 임시 탭입니다. 기존 의뢰·성장·운영 기능은 작업실 화면 및 성장·운영 창에서 유지합니다.

## 문서
- `CHATGPT_PROJECT_INSTRUCTIONS.md`: ChatGPT 프로젝트 설정에 붙여넣는 지침
- `AGENTS.md`: 코드 작업 에이전트용 안내
- `docs/GAME-DESIGN.md`: 현재 게임과 재화 사용처의 기획 상태
- `docs/PROJECT-STATUS.md`: 진행 현황 및 다음 작업
- `docs/CHANGELOG.md`: 변경 기록

## 개발 도구
- [상점 아이템 편집기](tools/shop-editor.html): 아이템 정보·효과·아이콘 설정, 로컬 편집 저장, JSON 가져오기·내보내기
- [상점 아이템 데이터](data/shop-items.json): 초기 예시 — 탄산음료 2,200원 / 사용 시 피로도 -10
- `node tests/shop-item-data.test.js`: 아이템 시드·도구 정적 검사

아이템 편집기는 **게임과 별도로 사용하는 개발용 페이지**입니다. 내보낸 JSON 파일만으로 게임 상점 구매/사용 시스템이 자동 구현되지는 않습니다. 아이콘 원본과 아이템 JSON은 GitHub에 따로 반영해야 합니다.

## 리소스와 저장
작업실 배경·썸네일과 Pretendard 폰트는 `assets/`에 있으며, 아이템 아이콘은 `assets/shop/`에 저장합니다. 이전 장비 업그레이드 기능은 제거되었으므로 `03-equipment.webp`는 필요하지 않습니다. 기존 장비 점검 이벤트는 업그레이드와 별개로 유지합니다.

실제 플레이 진행 데이터(개인 브라우저 저장 JSON)는 소스 저장소에 자동 업로드하지 않습니다.

## 상점 첫 번째 아이템
- 탄산음료: 2,200원, 즉시 피로도 10 감소(0 미만으로는 감소하지 않음)
- 상점에서 구매하면 인벤토리에 보관되며, 인벤토리의 사용 버튼을 누를 때 효과 적용
- 재화 부족 시 구매 불가, 피로도 0에서는 사용 버튼 비활성화
- 제작 데이터: `data/shop-items.json`; 아이콘: `assets/shop/soft-drink-red.png`
- 기존 엔진 저장 포맷 v3와 브라우저 저장 키는 유지

게임의 상점은 `data/shop-items.json`의 아이템 목록을 읽습니다. 현재 게임 엔진은 피로도 감소형 아이템만 실제 구매·사용을 지원합니다. 다른 제작 도구 효과 유형은 향후 설계 대상입니다.

## 의뢰 밸런스
- 신규 의뢰의 작업 시간·기본 보상금은 `engine.js`의 `JOB_BALANCE`에 정수 분 단위 구간으로 정의되어 있습니다. 전체 12종 범위는 `docs/GAME-DESIGN.md` 참조.
- 식비는 게임 **1일 50,000원**, **7일마다 350,000원**이 자동 지출됩니다.
- 성장·외주 보정은 기존 방식 유지. 과거에 생성된 의뢰의 저장값에는 소급 적용하지 않습니다.
- 검사: `node tests/economy-balance.test.js`

## 초기 자금 및 작업실 홍보
- 새로운 작업실 시작 시 **100,000원** 지급. 기존 세이브 잔액은 변경하지 않습니다.
- 작업실 홍보: **100,000원**, 게임 시간 16시간 동안 의뢰 도착 확률 +5%p(기존 효과 유지).
- 주간 식비: 게임 7일마다 175,000원 (이전 확정 수치 유지).
- 검사: `node tests/starting-money-promotion.test.js`

## 오프라인 진행과 상점 업그레이드
- 페이지 종료 및 백그라운드 시간은 오프라인으로 처리합니다. 해당 시간의 의뢰 작업 진행률, 수면·피로, 식비 지출은 정상 유지됩니다.
- 오프라인 의뢰 납품 보상금 및 EXP 기본 10%. 온라인 납품은 100%. 그림 연습도 오프라인 EXP 보정.
- 상점의 **액정 타블렛**은 오프라인 보상금, **의자**는 오프라인 EXP를 업그레이드합니다.
- Lv.0~5, 각 단계 증가 +3/+5/+7/+10/+15%p → 보상률 10/13/18/25/35/50%.
- 강화 가격: 250,000 / 750,000 / 1,500,000 / 5,500,000 / 20,000,000원 (각 아이템).
- 관련 원본 아이콘: `assets/shop/pen-tablet.png`, `assets/shop/chair.png` (32×32 투명 PNG).
- 저장 키·v3 저장 데이터 호환 유지. 기존 저장에 없던 강화 단계는 Lv.0.
- 테스트: `node tests/offline-upgrades.test.js`

## 그림 연습과 상점 패널 (2026-10-11)
- 연습: **게임 30분 / 2 EXP**. 기존 저장의 240분 기준 진행도는 비례 변환.
- 식비: 게임 하루 25,000원에 해당하며 **7일마다 175,000원** 일괄 지출.
- 상점 오른쪽 패널 위에 액정 타블렛/의자 업그레이드, 아래에 인벤토리 영역. 모바일은 상품 목록 아래에 배치.
- 인벤토리는 소모품을 아이템별로 묶어 수량(×N)을 표시하고 '사용' 시 1개씩 소비합니다.
- 테스트: `node tests/practice-shop-layout.test.js`

## 인벤토리 사용 (2026-10-11)
- 탄산음료 구매: **2,200원 지불 → 인벤토리 수량 +1**. 피로도는 구매 시 변화하지 않음.
- 인벤토리: 각 항목의 아이콘 오른쪽 아래 ×N, 상품명, **사용** 버튼. 사용 시 수량 -1, 피로도 -10 (최저 0).
- 피로도 0이어도 구매 가능하지만 사용은 불가. 현재 소모품의 수량은 v3 게임 세이브의 `inventory`에 저장되며 기존 세이브는 빈 인벤토리로 시작.
- 검증: `node tests/shop-purchase.test.js`
